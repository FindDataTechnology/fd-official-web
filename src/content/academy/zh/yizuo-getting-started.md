## 学完你能做什么

用壹座完成第一个可交付任务：把自有资料喂进文档库、装上一个行业能力包、让它带真实工具调用产出结论，最后交出一条匿名可读的分享链接。全程在浏览器里完成，不需要装任何软件、不需要命令行。

## 前置条件

- 一个平台账号（由组织或平台运维开通，登录走单点登录）。
- 一个浏览器；准备 1–2 份自己的资料（PDF、Markdown、纯文本，或一个网页地址均可）。

## 步骤

### 1. 登录，先认清工作台的地图

打开平台入口（用组织账号登录，走单点登录，全程不需要额外输密码）。默认落在对话页，这一步先知道各个位置分别管什么。

| 位置 | 用来做什么 |
| --- | --- |
| `/chat` | 对话主页（默认页）：流式思考过程、工具调用、技能执行，右上角可切模型与 agent |
| `/knowledge` | 文档库：导入 PDF / Markdown / 文本 / 网页 URL，做检索增强 |
| `/agents` | 智能体与应用目录（含能力包带来的角色） |
| `/tasks` | 定时任务，可配通知 |
| 资源库（左侧导航）| 图表等产出自动入库 |
| 调用追踪（左侧导航）| 每回合的工具调用记录——验证「真的调了工具」的地方 |
| 设置（左下角）| 通用、账号、模型、技能、能力包、自建预设等 |

### 2. 让回答基于你自己的资料

进左侧导航的资料库导入 1–2 份自己的资料（PDF、Markdown、纯文本，或直接给一个网页 URL）。回到对话页，提一个答案只在你资料里的问题，确认它引用的是你的材料，而不是泛泛而谈。这一步把「通用助手」变成「懂你业务的助手」。

### 3. 装一个能力包，把行业能力接进来

1. 平台左下角「设置」→「能力包」。
2. 先点「连接市场」：跳到登录页后选「使用组织账号继续」——共享会话，全程不输密码，系统会为你铸一枚 7 天个人令牌。装市场来源的能力包需要这一步；没有凭据时会提示缺少凭据。这一步管理员代不了，必须你本人点一次。
3. 浏览市场 → 打开一个能力包详情 → 订阅 → 安装到运行时（「我的能力包」）。
4. 安装后能力分头落位：技能进「设置 → 技能」（即装即用）；外部工具进「设置 → 外部工具」；智能体角色出现在对话页的角色选择器里。

### 4. 用它做一件真活

新建一个会话，在 agent 选择器里选中刚装上的角色，提一条真实业务问题——不要用「你好」这类问题做验证。让它给出结论，需要的话让它出图表，图表会自动进资源库。

注意「聚焦模式」：选中具体 agent 后，可用工具会按它的角色收窄到该能力包声明的集合。这是设计，不是故障。

### 5. 看调用记录，自证不是幻觉

打开左侧导航的调用追踪页，找到刚才那一回合：你会看到技能执行，以及一条条真实的工具调用记录（工具名加它的返回）。这是判断「模型是不是真的调了数据」的可信方式，也是把结论交给同事之前该做的自检动作。

### 6. 交付出去

在会话菜单里选分享，得到一条匿名只读链接——匿名也能打开。把链接发给同事，你的第一个可交付任务就完成了。

## 自检

- 资料生效：提一个只有你导入材料里才有答案的问题，回答能引用到你的资料。
- 工具真实：在调用追踪页里找到至少一条工具调用记录（含工具名与返回）。
- 交付可用：用无痕窗口打开分享链接，未登录也能看到完整会话。

## 下一步

能力接进来之后，下一步是把它变成你自己的固定工作流：进入课程二《萬星与谦面协作入门》，用「自建预设」把技能和外部工具组合起来，再把工作流部署成服务、给程序调用。

配套能力包：本课的双载体能力包在市场上架后即可获取——届时在平台左下角「设置」→「能力包」按课程名搜索订阅安装；上架状态以本页下方入口为准（未上架时显示「准备中」）。

## 如果没成功

- **连接市场时登录页打不开或提示失败**：这是组织账号单点登录的问题，找平台运维确认账号已开通；页面打不开也可能是网络限制，换一个常用网络再试。
- **装完能力包，对话页里找不到刚装的角色**：回「设置 → 技能」确认技能确实装上了；角色选择器在对话页顶部，刷新页面后重新打开。只有技能装上而工具没装上，多数是因为漏了「连接市场」那一步。
- **调用追踪页里看不到工具调用**：说明这一回合模型没去查数据，只是口头回答。换一种问法，要求它「引用数据来源并给出查询过程」，再跑一轮。
- **分享链接打不开或要登录**：确认发出去的是完整链接（不要手动截断）；仍不行就在会话菜单里重新生成一次。
