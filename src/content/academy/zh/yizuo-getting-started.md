## 学完你能做什么

用壹座完成第一个可交付任务：把自有资料喂进文档库、装上一个行业功能集、让它带真实工具调用产出结论，最后交出一条匿名可读的分享链接。全程在浏览器里完成，不需要装任何软件、不需要命令行。

## 前置条件

- 一个平台账号（由组织或平台运维开通，登录走单点登录）。
- 一个浏览器；准备 1–2 份自己的资料（PDF、Markdown、纯文本，或一个网页地址均可）。

## 步骤

### 1. 登录，先认清工作台的地图

打开平台入口 `platform.finddatatech.cloud`，用组织账号登录。默认落在对话页，这一步先知道各个位置分别管什么。

| 位置 | 用来做什么 |
| --- | --- |
| `/chat` | 对话主页（默认页）：流式思考过程、工具调用、技能执行，右上角可切模型与 agent |
| `/knowledge` | 文档库：导入 PDF / Markdown / 文本 / 网页 URL，做检索增强 |
| `/agents` | 智能体与应用目录（含功能集带来的 agent） |
| `/tasks` | 定时任务，可配通知 |
| `/resources` | 资源库：图表等产出自动入库 |
| `/trace` | 每回合的调用追踪——验证「真的调了工具」的地方 |
| `/settings/<section>` | 设置：通用、账号、模型、MCP、技能、功能集、自建预设等 |

### 2. 让回答基于你自己的资料

进 `/knowledge` 导入 1–2 份自己的资料（PDF、Markdown、纯文本，或直接给一个网页 URL）。回到对话页，提一个答案只在你资料里的问题，确认它引用的是你的材料，而不是泛泛而谈。这一步把「通用助手」变成「懂你业务的助手」。

### 3. 装一个功能集，把行业能力接进来

1. 设置 → 功能集（`/settings/packs`）。
2. 先点「连接 MCP 市场」：跳到登录页后选 Continue with Logto——共享会话，全程不输密码，系统会为你铸一枚 7 天个人令牌。装市场来源的 MCP 需要这一步，没有凭据时会报 `credential-required`；这一步管理员代不了，必须你本人点一次。
3. 浏览市场 → 打开一个套件详情 → 订阅 → 安装到运行时（「我的功能集」）。
4. 安装后能力分头落位：技能进「设置 → 技能」（热加载，即装即用）；MCP 进「设置 → MCP」；agent / 角色出现在对话页的 agent 选择器里。

### 4. 用它做一件真活

新建一个会话，在 agent 选择器里选中刚装上的角色，提一条真实业务问题——不要用「你好」这类问题做验证。让它给出结论，需要的话让它出图表，图表会自动进资源库。

注意「聚焦模式」：选中具体 agent 后，可用工具会按它的角色收窄到该功能集声明的集合。这是设计，不是故障。

### 5. 看 trace，自证不是幻觉

打开 `/trace`，找到刚才那一回合：你会看到技能执行，以及形如 `mcp__<server>__<tool>` 的真实工具调用记录。这是判断「模型是不是真的调了数据」的可信方式，也是把结论交给同事之前该做的自检动作。

### 6. 交付出去

在会话菜单里选分享，得到一条 `/share/:token` 只读链接——匿名也能打开。把链接发给同事，你的第一个可交付任务就完成了。

## 自检

- 资料生效：提一个只有你导入材料里才有答案的问题，回答能引用到你的资料。
- 工具真实：在 `/trace` 里找到至少一条 `mcp__<server>__<tool>` 调用记录。
- 交付可用：用无痕窗口打开分享链接，未登录也能看到完整会话。

## 下一步

能力接进来之后，下一步是把它变成你自己的固定工作流：进入课程二《萬星与谦面协作入门》，用「自建预设」组合技能与 MCP，再把工作流部署成服务、给程序调用。

配套谦面 pack：本课的双载体功能集在谦面市场（`facet.finddatatech.cloud`）上架后可获取，届时在壹座「设置 → 功能集」按课程名搜索即可订阅安装；市场地址将在 pack 发布后回填本页。
