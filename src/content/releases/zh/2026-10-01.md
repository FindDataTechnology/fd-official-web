今天，房子的外面追上了里面。

## 每个公开仓都挂上了自己的线

九个公开仓库全部公开亮明所属产品线：README 横幅、仓库描述前缀、topic 标签三处一致——
`[wire]` 是开放数据供给线，`[facet]` 是本地平台线，`[constellation]` 是行业包生态线。
旗舰 `fd-open-data-mcp` 的真 README 也回来了——此前一次文档事故让一篇数据库迁移归档
顶在项目门面上当了几周首页。现在它是双语的项目自述了。

## 柏讯长出商业版

柏讯线产品页新增**云端数据联邦**——开源核心的托管登录门控版：五库联邦（统计年鉴、
中国法律、世界银行、GTA 上市公司面板、中国城市面板）加统一指标注册表，经一个 MCP
端点供给。同一动作里，它的源码离开了公网：商业服务一律镜像交付，历史 PyPI 版本已
yank。开源核心、闭源商业版——这条边界现在是写下来的规则，不再是意外。

## 两个产品，两扇新门

`platform.finddatatech.cloud` 与 `router.finddatatech.cloud` 已上线。旧地址
（`craw.`、`token.`）并行应答 30 天后转为永久重定向——门上的名字终于和门后的产品
对上了：Platform 对话基座，以及 FindDataRouter——同时给平台行业包 agent 供模的
AI API 网关。

## Router 纳入托管

FindDataRouter 的部署不再靠手艺：清单进了 GitOps 仓库，可从代码重建、镜像钉版本。
一个在售服务没有基础设施即代码是一笔债，还上了。
