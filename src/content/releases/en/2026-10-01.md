Today the outside of the house caught up with the inside.

## Every public repo wears its line

All nine public repositories now carry their product line openly: the README
banner, the repo description prefix, and the topic tags all say which line a
package belongs to — `[wire]` for the open-data supply line, `[facet]` for the
local platform line, `[constellation]` for the vertical-pack ecosystem. The
flagship `fd-open-data-mcp` also got its real README back — a documentation
accident had left a database-migration archive standing in as the project's
front page. It is a project readme again, in both languages.

## Wire grows a commercial edition

The Wire line page now lists **Cloud Data Federation** — the hosted, login-gated
edition of the open core: five federated databases (statistical yearbooks,
Chinese law, World Bank, GTA listed-company panel, China city panel) plus the
unified indicator registry, served through one MCP endpoint. In the same move
its source code left the public internet: the commercial service ships as
container images only, and its historical PyPI releases are yanked. Open core,
closed commercial edition — that boundary is now a written rule, not an
accident.

## Two products, two new front doors

`platform.finddatatech.cloud` and `router.finddatatech.cloud` are live. The old
addresses (`craw.`, `token.`) keep answering for a 30-day parallel period and
will then redirect permanently — the names on the door finally match the
products behind them: the Platform conversation base, and FindDataRouter, the
AI API gateway that also powers the platform's vertical-pack agents.

## The router is under management

FindDataRouter's deployment is no longer hand-crafted: it lives as a managed
manifest in our GitOps repository, rebuildable from code, pinned to a known
image. A selling service with no infrastructure-as-code was a debt we are glad
to have repaid.
