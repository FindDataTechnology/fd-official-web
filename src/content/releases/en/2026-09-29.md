## Wire

- **Search that understands meaning** — finding an indicator no longer means
  guessing its exact code or name: the open-data MCP's search now matches
  semantically across indicator names, aliases, and descriptions.
- **Reads you can audit** — registry reads now state which source and scope
  each figure came from, and indicators carry explicit scopes, so every number
  in an answer can be traced to where it lives.

## Lex

- **Legal search joins the MCP** — the business MCP gained four new tools over
  the legal corpora: search and read across legal documents (`legal_docs`) and
  guiding cases (`guide_cases`), so agents ground legal answers in the same
  platform they already query for data.
