DAAS now ships under the Wire line (寻数·柏讯) — the data line: the ledger that feeds every campaign.

## One command, the whole platform

One curl command installs everything. The entire platform lives in a single
SQLite file served by the merged fd-daas-mcp server — 161 MCP tools and 18
Claude Code skills in one install, with `doctor` and `selfcheck` health checks
built in.

## Yours, locally

It runs on your machine, and the data stays in your hands — the same
self-hosted principle as the rest of FindData, applied to your personal
workflows.
