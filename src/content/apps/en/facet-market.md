The Facet Marketplace is the supply face of the Facet line (寻数·谦面) — a thousand facets, everyone assembling their own text-and-data AI workflows. The marketplace turns those workflows into reusable packs: skills and tools get packaged, listed, subscribed to, and installed into the AI editor you already use with a single command. Alongside the packs sits an MCP service catalog that connects editors and agents to external tools after one configuration. Browsing is anonymous; publishing and subscribing need an account.

## Packs: browse, subscribe, publish

Every pack carries a full detail page, versions, and tags. Subscribing follows its updates; publishing is where creators ship new versions. It is the same market as the Store embedded in Platform (壹座), on one identity — packs you subscribe to here are on record in Platform's Store too.

## The MCP service catalog

Beyond skill packs, the market lists MCP services: standardized access points for external data and tools. Browse, read the notes, take the address — editors and agents gain the capability after one configuration.

## One command into your editor

```
npx @finddatatechnology/facet install <pack id> --target claude-code|cursor
```

An install is a version snapshot: what lands in your project has a definite version. The CLI is published on npm as `@finddatatechnology/facet`, targeting Claude Code and Cursor.
