The [Wire platform](https://wire.finddatatech.cloud) is the Wire line (寻数·柏讯) data platform itself: from your own data to a shareable dashboard, one self-service loop that runs entirely in the browser. Sign in with a FindData account (Logto SSO) to start.

## A free-tier loop that runs without AI

- **Build datasets** — CSV/Excel upload, or pull through the local connector; starting costs nothing.
- **Correct rows in place** — edit directly in the table with single-row rollback; dangling rows are labeled as such, never dressed up as clean.
- **Assemble dashboards** — a blank board plus a visual editor, with four panel types: KPI, line, bar, and table.
- **Bind queries** — each panel binds to one dataset query: pick the dataset, pick columns, set filters, sort order, and a row limit.
- **Preview** — run a trial fetch on the binding and see the data before it lands on the panel.
- **Refresh deterministically** — re-fetch by binding into a new version, with no LLM anywhere in the loop; the refresh is reproducible.
- **Export** — one click to CSV, per dataset or for the whole dashboard.
- **Publish and share** — publishing issues a signed share link that pins a version, carries a selectable expiry (7/30/90 days), and is noindex to search engines.

## The AI path (dedicated cell)

Conversational dashboard drafting (AI drafts promoted by hand), headless AI refresh, connectors, derived transforms, joins, bulk writes, and the MCP tool surface. This layer requires a provisioned dedicated cell and is delivered privately.

## Pipelines and scheduling

Derived datasets form lineage pipelines; the pipeline view states depth, cycle detection, and anomalies as they are. Cron-scheduled refresh covers datasets and dashboards alike, re-fetching on schedule.

## Data requests

If the catalog lacks data you need, file a data request — source URL, expectations, and refresh cadence. The platform side evaluates and delivers; once delivered, the data scope opens on your account automatically.

## Source packs

Preset open-data catalog packs by theme — statistical-yearbook panorama, regional economy, money and finance, and more. Subscribe and the whole themed catalog is yours.
