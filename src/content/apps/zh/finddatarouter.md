FindDataRouter 是寻数科技的 AI API 网关，也是「寻数·萬星」线的第一颗星，产品名
**萬星·词元**。这条线的方向：人与人经由各自的智能体相连——智能体自主采集信息、
彼此深度协作。而在智能体对话之前，先要有身份与通往智能的路由——这个网关两者皆是。
它把多家模型提供方统一在一个入口后面，同时也是寻数科技自有产品矩阵的模型调用
底座——Platform 与 LawBench 的模型调用都经由这个网关。

## 多家模型，一个入口

应用无需逐一对接每家模型提供方，只需接入唯一的网关入口。网关位于多家模型提供方
之前，把每个请求转发到所请求的模型。chat 入口同时说 OpenAI 与 Anthropic 两套
事实标准协议，既有应用无需改造。

## 按用户发放密钥

每个用户有自己的密钥。密钥按用户发放与管理，各自带有独立的配额，用量可归属到
具体用户。余额与消费窗口是财务硬顶，不会产生意外账单。

## 多渠道故障转移

同一模型可由多个渠道服务。某个渠道失败或配额耗尽时，请求会自动升级到可用渠道，
而不是直接报错。

## 模型车道：chat 之外的多类能力

在 chat 订阅池之外，词元还提供三类非 chat 模型能力——**语音、重排、搜索**，并支持
**视频生成**。它们与 chat 共用同一把 API 密钥、同一余额与消费窗口、同一用量面板：
换能力不换身份。

- **语音**（`/v1/audio/transcriptions`、`/v1/audio/speech`）：OpenAI 音频事实标准
  形状的转写与合成，按音频时长与合成字符数计量。
- **重排**（`/v1/rerank`）：Cohere/Jina 式形状，提交 query 与文档集取回按相关度
  排序的结果，按请求计量。
- **搜索**（`/v1/search`）：统一信封协议——一个 engine 选择器接入多家搜索供应商，
  换 engine 调用者零改造，按次计量。
- **视频生成**（`/v1/contents/generations/tasks`）：异步任务协议——创建任务取回
  任务 ID，轮询同路径查询状态，完成后取回结果；与 chat 共用同一把密钥与余额，
  按生成用量计费，任务失败不计费。

上游供应商可插拔：同一模型名背后的供应商变更时，对外协议形状与响应语义不变。
