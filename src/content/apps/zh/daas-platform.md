DaaS 现属柏讯线（寻数·柏讯）——数据线：给每一场营销供数的账本。平台保持本地、保持是你的。

## 一条命令，整个平台

一条 curl 命令完成安装。整个平台落在单个 SQLite 文件里，由合并后的 fd-daas-mcp 服务器统一对外——161 个 MCP 工具、18 个 Claude Code 技能，内置 `doctor` 与 `selfcheck` 健康检查。

## 数据在你手里

它在你自己的机器上运行，数据始终在你手里——与寻数其余产品一致的自托管原则，落到你的个人工作流上。
