谦面功能集市场是寻数·谦面线的对外供给面——千人千面，人人搭建自己的文本与数据 AI 工作流。市场把这些工作流沉淀成可复用的「功能集」：技能与工具被打包上架、被订阅使用，一行命令装进你常用的 AI 编辑器；另有一份 MCP 服务目录，让编辑器与智能体一次配置即可调用外部工具。匿名即可浏览，登录后可发布与订阅。

## 功能集：浏览、订阅、发布

每个功能集有完整详情、版本与标签；订阅即持续关注它的更新，发布是创作者交付新版本的入口。市场与壹座（Platform）内嵌的 Store 是同一个市场、同一套身份——在谦面市场的订阅，在壹座的 Store 里同样在册。

## MCP 服务目录

除技能包之外，市场还汇集 MCP 服务：外部数据与工具的标准化接入点。浏览、查看说明、拿到接入地址——编辑器和智能体在一次配置之后便具备调用能力。

## 一行装进编辑器

```
npx @finddatatechonology/facet install <包 id> --target claude-code|cursor
```

安装是版本快照：装进项目的内容有确定版本。CLI 已发布在 npm（`@finddatatechonology/facet`），支持 Claude Code 与 Cursor 两类目标。
