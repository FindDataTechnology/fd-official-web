## 要解决的问题

AI 智能体需要真实世界的数据——股价、宏观指标、政府统计、SEC 公告。但今天每个数据源都有自己的 API、自己的单位、自己的脾气。智能体只能硬编码针对某个数据源的调用，数据源一变、一挂，就全部失效。

## 它是什么

fd-open-data-mcp 是覆盖全球开放数据的**语义概念层**。你不再需要调用具体数据源的 API，而是以**概念与实体**的方式提问：

- 查询*贵州茅台*的 `price.close`——而不是"用 akshare 的 stock_zh_a_hist 查 600519"
- 查询*中国*的 `gdp.current_usd`——而不是去背一个世界银行指标代码

服务器会把每个概念解析到**所有承载它的数据源**，按数据质量排序，源故障时自动转移，并按计划刷新缓存值。一个协议，一个 MCP，全源数据。

## 当前规模

- **15 个指标概念**，覆盖金融、宏观与行业领域
- **45 个 MCP 工具**——目录、实体标识、语义层、实体图谱、向量检索、数据拉取、定时刷新、抓取策略
- **已接入主要数据源**：akshare、yfinance、SEC EDGAR、世界银行，以及不断扩充的中国政府与行业数据

## 它在生态中的位置

服务通过 streamable HTTP 提供 MCP 协议——可接入 Claude、Cursor 或任何 MCP 客户端，也可以直接在[在线演示](/zh/demo)中体验。它是 [fd-open-data-protocol](/zh/repos/fd-open-data-protocol) 的参考实现，也是组织内其他项目的数据基座。

完整技术文档——安装、配置、工具参考——见[项目页面](/zh/repos/fd-open-data-mcp)。
